                                                • 16S rRNA (扩增子测序) 分析流程

                                                （一）软件安装

                                                ​x
                                                # 本流程使用QIIME 2 (2026.07版本)
                                                conda env create --name qiime2 --file https://raw.githubusercontent.com/qiime2/distributions/refs/heads/dev/2026.7/qiime2/released/rachis-qiime2-linux-64-conda.yml
                                                

                                                # 激活conda虚拟环境
                                                conda activate qiime2
                                                

                                                # 验证安装
                                                qiime info
                                                

                                                # 依赖软件 FastQC, MultiQC安装
                                                # FastQC 是看单个FASTQ的基本质量，MultiQC 把多个 FastQC 报告整合到一个 HTML。
                                                conda install -c bioconda fastqc
                                                conda install -c bioconda multiqc

                                                 

                                                （二）Fastq质控：FastQC / MultiQC

                                                xxxxxxxxxx
                                                mkdir -p fastqc_results multiqc_results
                                                

                                                fastqc -t 16 *.fastq.gz -o fastqc_results
                                                

                                                multiqc fastqc_results -o multiqc_results
                                                

                                                # 注：所有fastq文件应压缩为fastq.gz文件

                                                 

                                                （三）判断Primer、Barcode、demultiplex 状态

                                                情况A：已经 demultiplex，primer 也已经删除，直接导入QIIME 2即可 例如：

                                                xxxxxxxxxx
                                                Bat001_R1.fastq.gz
                                                Bat001_R2.fastq.gz
                                                

                                                Bat002_R1.fastq.gz
                                                Bat002_R2.fastq.gz

                                                情况B：已经 demultiplex，但 primer 还在，则需要Cutadapt 去 primer 例如R1：

                                                xxxxxxxxxx
                                                GTGYCAGCMGCCGCGGTAA + V4 sequence
                                                ^^^^^^^^^^^^^^^^^^^
                                                515F

                                                情况C：还没有 demultiplex，不能直接导入 例如一个FASTQ混了：

                                                xxxxxxxxxx
                                                barcode1 + sample A
                                                barcode2 + sample B
                                                barcode3 + sample C

                                                 

                                                （四）软件使用

                                                (1) 准备manifest.tsv文件

                                                xxxxxxxxxx
                                                sample-id forward-absolute-filepath reverse-absolute-filepath
                                                Bat01 /path_to/sample1_1.fastq.gz /path_to/sample1_2.fastq.gz
                                                Bat02 /path_to/sample2_1.fastq.gz /path_to/sample2_2.fastq.gz
                                                Bat03 /path_to/sample3_1.fastq.gz /path_to/sample3_2.fastq.gz

                                                 

                                                (2) 导入QIIME 2

                                                xxxxxxxxxx
                                                qiime tools import \
                                                  --type 'SampleData[PairedEndSequencesWithQuality]' \
                                                  --input-path manifest.tsv \
                                                  --output-path demux.qza \
                                                  --input-format PairedEndFastqManifestPhred33V2
                                                

                                                # Example:
                                                qiime tools import --type 'SampleData[PairedEndSequencesWithQuality]' --input-path manifest.tsv --output-path demux.qza --input-format PairedEndFastqManifestPhred33V2

                                                 

                                                (3) 可视化导入结果

                                                xxxxxxxxxx
                                                # 检查每个样本read数、R1/R2每个位点的quality、序列长度，确定后续分析中trunc-len-f，trunc-len-r参数
                                                qiime demux summarize --i-data demux.qza --o-visualization demux.qzv

                                                .qzv和.qza文件可通过在线网站可视化：https://view.qiime2.org/

                                                 

                                                (4) DADA2去噪

                                                xxxxxxxxxx
                                                qiime dada2 denoise-paired \
                                                  --i-demultiplexed-seqs demux.qza \
                                                  --p-trim-left-f 0 \     # 正向序列5'端截掉的碱基数（去除低质量开头）
                                                  --p-trim-left-r 0 \     # 反向序列5'端截掉的碱基数（去除低质量开头）
                                                  --p-trunc-len-f 240 \   # 正向序列保留的长度，由FastQC和demux.qzv结果确定
                                                  --p-trunc-len-r 160 \   # 反向序列保留的长度，由FastQC和demux.qzv结果确定
                                                  --p-n-threads 0 \       # 使用所有可用 CPU 核心
                                                  --o-table table.qza \
                                                  --o-representative-sequences rep-seqs.qza \
                                                  --o-denoising-stats denoising-stats.qza \
                                                  --o-base-transition-stats base-transition-stats.qza
                                                

                                                # Example:
                                                qiime dada2 denoise-paired --i-demultiplexed-seqs demux.qza --p-trim-left-f 0 --p-trim-left-r 0 --p-trunc-len-f 240 --p-trunc-len-r 160 --p-n-threads 0 --o-table table.qza --o-representative-sequences rep-seqs.qza --o-denoising-stats denoising-stats.qza --o-base-transition-stats base-transition-stats.qza

                                                 

                                                (5) 查看去噪统计

                                                xxxxxxxxxx
                                                qiime metadata tabulate \
                                                  --m-input-file denoising-stats.qza \
                                                  --o-visualization denoising-stats.qzv
                                                

                                                # Example:
                                                qiime metadata tabulate --m-input-file denoising-stats.qza --o-visualization denoising-stats.qzv

                                                 

                                                (6) 汇总特征表 metadata

                                                创建metadata.tsv文件，例如：

                                                xxxxxxxxxx
                                                # metadata.tsv
                                                sample-id group family  diet
                                                Bat1  Bat A B
                                                Bat2  Bat A B
                                                Bat3  Bat A B
                                                xxxxxxxxxx
                                                # 查看每个sample有多少reads、每个Amplicon Sequence Variant总丰度是多少、ASV数量、样本sequencing depth分布
                                                qiime feature-table summarize \
                                                  --i-table table.qza \
                                                  --m-metadata-file metadata.tsv \
                                                  --o-feature-frequencies feature-frequencies.qza \
                                                  --o-sample-frequencies sample-frequencies.qza \
                                                  --o-summary table.qzv
                                                

                                                # Example:
                                                qiime feature-table summarize --i-table table.qza --m-metadata-file metadata.tsv --o-feature-frequencies feature-frequencies.qza --o-sample-frequencies sample-frequencies.qza --o-summary table.qzv
                                                

                                                # 注：在使用相同 PCR primers、相同扩增区域的研究之间可以做 ASV-level merge
                                                qiime feature-table merge \
                                                  --i-tables table1.qza table2.qza table3.qza \
                                                  --o-merged-table merged-table.qza

                                                 

                                                (7) 查看代表序列

                                                xxxxxxxxxx
                                                qiime feature-table tabulate-seqs \
                                                  --i-data rep-seqs.qza \
                                                  --o-visualization rep-seqs.qzv
                                                

                                                # Example:
                                                qiime feature-table tabulate-seqs --i-data rep-seqs.qza --o-visualization rep-seqs.qzv
                                                

                                                # 注：在使用相同 PCR primers、相同扩增区域的研究之间可以做 ASV-level merge
                                                qiime feature-table merge-seqs \
                                                  --i-data rep-seqs1.qza rep-seqs2.qza rep-seqs3.qza \
                                                  --o-merged-data merged-rep-seqs.qza

                                                 

                                                (8) 物种注释

                                                下载合适的classifiers

                                                xxxxxxxxxx
                                                # 下载链接：
                                                https://www.arb-silva.de/documentation/classifiers/qiime-2
                                                xxxxxxxxxx
                                                qiime feature-classifier classify-sklearn \
                                                  --i-classifier SILVA144_XXXXX.qza \ #选择合适的classifier
                                                  --i-reads rep-seqs.qza (或merged-rep-seqs.qza) \
                                                  --o-classification taxonomy.qza
                                                

                                                # Example:
                                                qiime feature-classifier classify-sklearn --i-classifier SILVA_144_SSURef_NR99_uniform_classifier_V4-515f-806r.qza --i-reads rep-seqs.qza (或merged-rep-seqs.qza) --o-classification taxonomy.qza

                                                (10) 过滤mitochondria / chloroplast (Optional)

                                                xxxxxxxxxx
                                                # 过滤table
                                                qiime taxa filter-table \
                                                  --i-table table.qza (或merged-table.qza) \
                                                  --i-taxonomy taxonomy.qza \
                                                  --p-exclude mitochondria,chloroplast \
                                                  --o-filtered-table table-filtered.qza (或merged-table-filtered.qza)
                                                

                                                # Example:
                                                qiime taxa filter-table --i-table table.qza (或merged-table.qza) --i-taxonomy taxonomy.qza --p-exclude mitochondria,chloroplast --o-filtered-table table-filtered.qza (或merged-table-filtered.qza)
                                                

                                                # 过滤rep-seqs
                                                qiime taxa filter-seqs \
                                                  --i-sequences merged-rep-seqs.qza \
                                                  --i-taxonomy taxonomy.qza \
                                                  --p-exclude mitochondria,chloroplast \
                                                  --o-filtered-sequences rep-seqs-filtered.qza (或merged-rep-seqs-filtered.qza)
                                                

                                                # Example:
                                                qiime taxa filter-seqs --i-sequences rep-seqs.qza (或merged-rep-seqs.qza) --i-taxonomy taxonomy.qza --p-exclude mitochondria,chloroplast --o-filtered-sequences rep-seqs-filtered.qza (或merged-rep-seqs-filtered.qza)

                                                  --o-sample-frequencies sample-frequencies-filtered.qza \

                                                (13) Phylogeny

                                                xxxxxxxxxx
                                                qiime phylogeny align-to-tree-mafft-fasttree \
                                                  --i-sequences rep-seqs-filtered.qza (或merged-rep-seqs-filtered.qza) \
                                                  --o-alignment aligned-rep-seqs.qza \
                                                  --o-masked-alignment masked-aligned-rep-seqs.qza \
                                                  --o-tree unrooted-tree.qza \
                                                  --o-rooted-tree rooted-tree.qza
                                                

                                                # Example:
                                                qiime phylogeny align-to-tree-mafft-fasttree --i-sequences rep-seqs-filtered.qza (或merged-rep-seqs-filtered.qza) --o-alignment aligned-rep-seqs.qza --o-masked-alignment masked-aligned-rep-seqs.qza --o-tree unrooted-tree.qza --o-rooted-tree rooted-tree.qza

                                                 

                                                (14) Diversity

                                                xxxxxxxxxx
                                                qiime diversity core-metrics-phylogenetic \
                                                  --i-phylogeny rooted-tree.qza \
                                                  --i-table table-filtered.qza (或merged-table-filtered.qza) \
                                                  --p-sampling-depth 19000 \ # --p-sampling-depth参数通常选择最小样本序列数或覆盖大多数样本的值（根据table-filtered.qzv判断）
                                                  --m-metadata-file metadata.tsv \
                                                  --output-dir core-metrics
                                                

                                                # Example:
                                                qiime diversity core-metrics-phylogenetic --i-phylogeny rooted-tree.qza --i-table table-filtered.qza (或merged-table-filtered.qza) --p-sampling-depth 19000 --m-metadata-file metadata.tsv --output-dir core-metrics

                                                # Example:

                                                # (2) Faith PD 指数组间差异

                                                  --m-metadata-file metadata.tsv \
                                                  --o-visualization faith-pd-group-significance.qzv
                                                

                                                # Example:

                                                (16) Beta 多样性组间差异检验（PERMANOVA）

                                                xxxxxxxxxx
                                                # (1) 基于 Bray-Curtis 距离的组间差异检验
                                                qiime diversity beta-group-significance \
                                                  --i-distance-matrix core-metrics/bray_curtis_distance_matrix.qza \
                                                  --m-metadata-file metadata.tsv \
                                                  --m-metadata-column group \
                                                  --o-visualization bray-curtis-group-significance.qzv \
                                                  --p-pairwise \
                                                  --p-method permanova
                                                

                                                # Example:
                                                qiime diversity beta-group-significance --i-distance-matrix core-metrics/bray_curtis_distance_matrix.qza --m-metadata-file metadata.tsv --m-metadata-column group --o-visualization bray-curtis-group-significance.qzv --p-pairwise --p-method permanova
                                                

                                                # (2) 基于 UniFrac 距离的组间差异检验 (Weighted UniFrac)
                                                qiime diversity beta-group-significance \
                                                  --i-distance-matrix core-metrics/weighted_unifrac_distance_matrix.qza \
                                                  --m-metadata-file metadata.tsv \
                                                  --m-metadata-column group \
                                                  --o-visualization weighted-unifrac-group-significance.qzv \
                                                  --p-pairwise \
                                                  --p-method permanova
                                                

                                                qiime diversity beta-group-significance --i-distance-matrix core-metrics/weighted_unifrac_distance_matrix.qza --m-metadata-file metadata.tsv --m-metadata-column group --o-visualization weighted-unifrac-group-significance.qzv --p-pairwise --p-method permanova
                                                

                                                # (3) 基于 UniFrac 距离的组间差异检验 (Unweighted UniFrac)
                                                qiime diversity beta-group-significance \
                                                  --i-distance-matrix core-metrics/unweighted_unifrac_distance_matrix.qza \
                                                  --m-metadata-file metadata.tsv \
                                                  --m-metadata-column group \
                                                  --o-visualization unweighted-unifrac-group-significance.qzv \
                                                  --p-pairwise \
                                                  --p-method permanova

                                                (18) 导出结果

                                                qiime tools export --input-path taxonomy.qza --output-path ./export/taxonomy
                                                

                                                qiime tools export --input-path rep-seqs-filtered.qza --output-path ./export/rep-seqs
